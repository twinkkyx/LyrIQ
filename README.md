# LyrIQ Website

High-impact, responsive website for **lyriq.co.in** built from:

- Existing live-site positioning and program content
- Latest achievements and roadmap shared by the LyrIQ team

## Included Sections

- Hero + value proposition (Credible, Accessible, Affordable)
- Current achievements (LPL 2025, workshops, student impact, national tie-ins)
- Flagship programs (Research Curriculum, Momentum, LPL)
- Impact Building roadmap (LPL 2026, LPL Accelerator, chapters, THEO, PenPal, Open Mics, crash courses, workshops)
- Partners and mentor spotlight
- Contact form block

## Local Preview

Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
